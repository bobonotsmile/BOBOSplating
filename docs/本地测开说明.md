# 开发与测试

产品介绍见 [README](../README.md)。本文面向源码维护者，命令用于本地开发，不是 Release 安装步骤。

## 源码开发

准备 .NET SDK 6.0.428（或兼容的 6.0 补丁）、Node.js 20 及以上兼容版本、pnpm 10.27.0。原生工具只在执行重建任务的主机上需要；仅开发页面或查看本地 PLY 不需要它们。

在项目根目录启动 API：

```text
dotnet run --project splat-backend/BoboSplat.Api.csproj
```

另一个终端进入 `web-frontend`：

```text
pnpm install --frozen-lockfile
pnpm dev
```

默认开发页面为 `http://127.0.0.1:9130`，API 为 `http://127.0.0.1:9131`。Vite 将 `/api` 代理到后端。可在项目根目录 `.env` 中设置 `BOBO_DEV_PORT` 与 `BOBO_BACKEND_URL`；该文件不提交 Git。

### 后端配置

后端读取进程环境变量或命令行参数，**不会自动加载 `.env`**。`.env.example` 是字段模板；Docker Compose 或 Windows 服务安装器应负责注入环境变量。使用命令行开发时，也可追加例如 `--Bobo:Tools:Brush=/absolute/path/brush_app`。

| 环境变量 | 默认值 / 说明 |
| --- | --- |
| `ASPNETCORE_URLS` | `http://127.0.0.1:9131` |
| `Bobo__DataRoot` | `./data`，相对于进程工作目录；长期运行应使用绝对路径 |
| `Bobo__Tools__Ffmpeg` | `ffmpeg` |
| `Bobo__Tools__Ffprobe` | `ffprobe` |
| `Bobo__Tools__Colmap` | `colmap`，针对 3.9.1 参数验证 |
| `Bobo__Tools__Brush` | `brush_app`，针对 0.3.0 参数验证 |
| `Bobo__MaxUploadBytes` | `1073741824` |
| `Bobo__MaxPendingJobs` | `20` |
| `Bobo__ProcessTimeoutMinutes` | `120`，单个工具进程超时 |
| `Bobo__MinRegistrationRatio` | `0.8` |

第一版面向可信的本地工作空间，尚未实现账户、多用户隔离与公网访问控制。任务队列存于内存，任务记录持久化；重新启动后需要重新提交中断任务。每个任务日志文件最多写入约 16 MiB，页面提供最近 250 行。当前没有自动清理数据的功能。

## 测试

Ubuntu 包由项目根目录 `publish-ubuntu.ps1` 生成，先检查本机所需基础镜像；脚本执行构建和测试、打包配置并导出应用镜像。前端静态资源在开发机通过 pnpm 构建，再写入网页镜像，目标机使用离线应用镜像。部署操作以包内说明为准。

本地镜像集成检查为 `python tests/verify-release-http.py`，只创建 `bobo-release-check` 测试项目并在结束后删除其容器和网络，测试数据保存在 tests 下。它明确省略 GPU 设备请求，并对成功训练使用工具替身；不能替代目标机 GPU 训练。

项目根目录 `tests/` 是维护者本地测试目录，不提交 Git。构建和测试在本地执行，项目不配置 GitHub CI/CD。

维护者本机保留 `tests/` 时，从项目根目录执行：

```text
dotnet build splat-backend/BoboSplat.Api.csproj -c Release
dotnet build tests/FakeEngine/FakeEngine.csproj -c Release
dotnet run --project tests/BoboSplat.Tests.csproj -c Release -- .
```

从 `web-frontend` 执行：

```text
pnpm test
pnpm build
```

C# 检查程序启动真实 HTTP 服务，覆盖上传校验、任务串行化、重建质量拦截、失败停止、取消、PLY 下载与重启状态。原生计算工具使用确定性的测试替身，这些测试不替代真实 GPU 重建验证。

可选浏览器检查：保持前端开发服务运行，在已安装 Edge 的开发机执行 `pnpm test:browser`。设置 `BOBO_TEST_PLY` 为本地 Gaussian PLY 路径时，还会验证真实文件加载、视角控制与窄屏布局；文件不会复制进仓库。`BOBO_UI_TEST_URL` 可覆盖测试页面地址，`BOBO_BROWSER_CHANNEL` 可切换浏览器。UI 视觉和操作体验最终由使用者验收。
