# BOBOSplating

[简体中文](README.md) | [English](README.en.md)

**面向 Windows / Linux 自部署的 3D Gaussian Splatting Web UI。**

把视频变成可以自由探索的三维场景。在自己的电脑或 GPU 服务器上部署 BOBOSplating，通过浏览器上传视频、启动重建、查看进度，再直接浏览或下载生成的 Gaussian PLY。

重建计算在部署机器上运行，浏览器负责操作和三维预览。素材、任务记录与训练结果保存在自己的部署机器上，适合个人和可信内网工作空间。

## 可以做什么

- **视频到三维场景**：上传 MP4、MOV、MKV 或 WebM，自动完成抽帧、相机重建和 Gaussian 训练。
- **两档重建质量**：选择「快速预览」先看效果，或「均衡重建」保留更多细节。
- **浏览器管理任务**：查看处理阶段、训练进度（引擎输出时）、耗时、重建质量和运行日志，随时取消任务。
- **后台持续计算**：任务依次执行，关闭页面后仍继续运行，可再次打开页面查看结果。
- **内置三维查看器**：旋转、平移、缩放查看重建场景，也能打开已有的本地 Gaussian PLY；本地预览文件不会上传到后端。
- **结果自己保存**：下载最终 PLY，供后续查看和使用。

## 使用流程

```text
上传视频 → 选择质量 → 自动重建与训练 → 网页查看 → 下载 PLY
```

默认支持最大 1 GiB、时长不超过 60 分钟的视频，按档位抽样到限定帧数。

| 档位 | 最多抽帧 | 训练步数 | Gaussian 上限 | 最大图片尺寸 |
| --- | ---: | ---: | ---: | ---: |
| 快速预览 | 80 | 5,000 | 500,000 | 1,280 |
| 均衡重建 | 160 | 15,000 | 1,000,000 | 1,600 |

适合使用同一镜头、固定焦段拍摄的静态场景视频。显存需求随素材而变化；生成的 Gaussian 场景用于新视角浏览，不是三角网格模型，也不包含运动物体的动画重建。

## 获取与运行平台

项目将通过 **GitHub Releases** 提供发布包。选择对应平台的包，按照包内的部署说明配置运行，再通过浏览器访问 Web UI。

Ubuntu 安装附件包含应用镜像和运行依赖，解压后通过 `install.sh` 统一安装，无需从镜像仓库下载应用或在服务器编译。安装目录可自行选择，完整部署说明随包提供。

| 平台 | 发布方式 |
| --- | --- |
| Windows x64 | 规划为原生 Windows 服务，采用 Caddy 和 NSSM；当前未提供安装包 |
| Linux（Ubuntu 24.04 x86_64） | Docker Compose 安装包，当前优先支持 |

## 安装前须知

| 项目 | Ubuntu 安装要求与限制 |
| --- | --- |
| 系统 | Ubuntu 24.04、x86_64（amd64）；不适用于 ARM 或 Windows 原生系统 |
| 显卡 | 支持 Vulkan 的 NVIDIA GPU，宿主机已安装兼容驱动；RTX 3060 12GB 为当前测试配置，不代表最低显存要求，其他显卡需实测 |
| 基础环境 | 已安装并可运行 Docker Engine、Compose v2；当前测试版本为 Docker 28 / Compose 2.34 |
| 安装权限 | 需要 sudo；若首次安装或配置 NVIDIA 容器运行时，需要确认重启 Docker，会影响同机其他容器 |
| 网页访问 | 安装时填写浏览器可访问的服务器 IP 或 DNS，默认 HTTPS 端口 9134；自签证书需在访问设备上配置浏览器信任 |
| 计算耗时 | 当前 COLMAP 特征提取和匹配使用 CPU，Brush 训练使用 GPU；匹配可能持续数分钟或更久，日志按处理块更新，耗时取决于 CPU、画面数量与内容 |

已验证 RTX 3060 主机视频到 PLY 流程，以及容器内 NVIDIA/Vulkan 显卡识别；经当前安装包完成的端到端训练、全新主机安装和 Windows 原生训练尚未完成验收。可下载的平台与具体验证范围以实际 Release 为准。

当前版本面向可信环境，尚无账户与多用户隔离。服务重启后，未完成任务需重新提交。

## 项目技术栈

| 部分 | 技术 |
| --- | --- |
| Web UI | Vue 3、JavaScript、Vite、pnpm |
| 后端与任务调度 | C#、ASP.NET Core 6 Web API |
| 视频抽帧 | FFmpeg / FFprobe |
| 相机位姿与稀疏重建 | COLMAP |
| Gaussian 训练 | Brush |
| 网页三维查看 | Three.js、Spark |

源码开发、配置与测试说明见 [本地测开说明](docs/本地测开说明.md)。
